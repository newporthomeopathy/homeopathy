# Newport Homeopathy Clinic

The Phase 2 rebuild uses Astro static output, TypeScript strict mode and plain CSS. The
Phase 1 website remains in `newporthomeopathy-main/` during migration.

## Commands

```sh
npm install
npm run dev
npm run check
npm run lint
npm run format:check
npm run build
```

The root preview page is intentionally `noindex` and is not launch content. Replace it
with the approved homepage before deployment.
